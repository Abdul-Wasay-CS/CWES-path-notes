`20 * ________+ ________ = 65535`

One way to solve this is by putting the factor as 0, then the other digit becomes Y

$20(0) + Y = 65535$
$Y = 65535$
$Y = 65535$
$20+65515 = 65535$

Now this is the simplest way since dealing variable in addition is alot easier than a variable with a factor. To understand this: Lets assume the  addition digit is 1 so the number becomes even:
$20X + 1 = 655335$
$20X = 655335-1$
$X = 655334/20$
$X = 32766.7$
$20(32766.7)+1=655335$

For the computer , the two methods arent much different,  but for humans the first method is much easier since it simplifies out the multiplication part of the equation.

In truth , the actual equation is:
$20X+Y=655335$ for all X,Y real values
so we can put any one value and the other one would come out.
