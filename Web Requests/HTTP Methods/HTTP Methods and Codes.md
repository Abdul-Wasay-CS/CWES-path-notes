## Use of methods other than GET or POST

Using REST API's rely on PUT and DELETE methods to update and delete data.

## Status Codes

-  **1xx:** only info ,  doesnt affect processing of request
-  **2xx:** Successful request
-  **3xx**: Redirection of client request
-  **4xx**: Improper request from client
-  **5xx**: Problem with HTTP server

For full list of stadard codes: https://developer.mozilla.org/en-US/docs/Web/HTTP/Status
