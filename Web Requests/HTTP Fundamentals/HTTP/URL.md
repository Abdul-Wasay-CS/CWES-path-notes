==**Note:** The only mandatory fields are the scheme and the host.== 

| Component | Description                                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| `Host`    | The host signifies the resource location. This can be a hostname or an IP address                                    |
| `Scheme`  | This is used to identify the protocol being accessed by the client, and ends with a colon and a double slash (`://`) |

**Path :** Points to resource being accessed, default = index.html
**Query String:** Passes additional data and parameter to server , structured in key = value, for multiple:use &.
