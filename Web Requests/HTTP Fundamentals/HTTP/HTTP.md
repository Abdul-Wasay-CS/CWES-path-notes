An application level protocol used to www.

Consists of client and a server.

## Functions:

- **Client**: requests resources from the server.
- **Server**: Processes the request and potentially returns the requested resource
## Ports
An HTTP port is a virtual door that guides data traffic to the correct application or service on the client or server.
