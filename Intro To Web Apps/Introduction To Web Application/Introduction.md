Key differences between web pages and web applications:
- Dynamic data and content
- Running on any display size
- Platform independant

## Web Apps vs OS Apps

**Web apps pros:**
- platform-independent
- do not consume any space on the end user's hard drive
- version unity
**OS apps pros**:
- Can utlize native OS libraries
- faster to load and interact
- more functionality due to native integration within the OS

## Security Risks of Web Apps

Since the web app's server also hosts many other sensitive web application and  databaes, if we can succefully breach a web app , we can use its communication to the server to potentially gain access to sensitive data hosted on the same server.

One of the most widely used method for testing web applications is [OWASP Web Security Testing Guide](https://github.com/OWASP/wstg/tree/master/document/4-Web_Application_Security_Testin)
